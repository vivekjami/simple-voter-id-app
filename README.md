# Voter List Page Builder (తెలుగు / English)

Static web app: fill 10 voter cards per page (only Name and Voter ID are required), choose Telugu / English / Both, then download an A4 PDF for printing. Data is kept in the browser (localStorage).

## Run locally
    npx serve .

## Deploy to Vercel
Import the repo in Vercel (Framework: Other, no build command, output dir = root), or run `npx vercel --prod`.
